# 浏览器检查

从仓库根目录运行 `npm run preview -- --qa`，浏览器打开以下本机地址。

| 地址 | 检查内容 |
| --- | --- |
| http://127.0.0.1:4386/wubi/ | 正式构建页面 |
| http://127.0.0.1:4386/wubi/__qa/ | 默认宽度与 axe 检查，结果显示在页面下方 |
| http://127.0.0.1:4386/wubi/__qa/?scale&spacing | 200% 文字、行高和文字间距 |
| http://127.0.0.1:4386/wubi/__qa/?instances | 两个不同宽度的组件、独立 ID 和样式隔离；按按钮检查卸载 |

检查 1280、390、320 像素视口，确认正文不随键盘整体横向溢出。键盘完整可见时应隐藏滚动提示。窄屏以方向键滚至 P，再恢复宽屏，确认滚动量与提示恢复。另用真实浏览器缩放检查 100% → 175% → 200% → 100%。

夹具依次加载正式产物和测试脚本，修改文字间距的样式只存在于验收页面。生产预览默认关闭 __qa 路由，dist 中也没有检查脚本。

vendor/axe.min.js 为 axe-core 4.10.3，保留原版权头，许可证见 [AXE-LICENSE](vendor/AXE-LICENSE)。离屏文字有时会进入 axe 的 incomplete 结果，此时补做主题色值对比度检查。[axe 官方版本](https://github.com/dequelabs/axe-core/tree/v4.10.3)
