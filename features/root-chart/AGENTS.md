# 字根图维护约定

本说明适用于本功能下的代码、数据、绘图脚本与文档。遵循仓库根 AGENTS.md 的站点约定。

## 文件与接口

src/root-chart.js 提供 `window.mountRootChart(container, data)`，返回卸载函数。它只操作自己的根节点，卸载时断开 ResizeObserver，字体就绪回调也应检查挂载状态。实例的说明与提示使用独立 ID。

data/wubi86.js 是当前页面及未来教程、练习共用的数据，采用普通脚本以兼容现有离线入口。组件样式在 src/root-chart.css 中限定到 .root-chart，主题变量来自 site/assets/site.css。

## 核形依据与取舍

1. 先读 docs/勘误.md 中对应键的完整清单、数量、原图差异和用户明确取舍。参考图在 docs/references/reference-chart.png，原稿为 original.jpg，来源和出版物页码见该目录 README。
2. J 根区为日、早、刂、虫，圈内两竖左短右长。K 根区只口，圈内川。H 圈内一竖，U 两点纵排，I 圈内为氵式三点，Z 为空灰框。
3. Q 两笔犬旁、删除卯左旁；Y 衣底归 E；X 区分幺、幺去点、纟，母外框和互中间框分别校对。其余取舍逐键查勘误。

## 绘图与间距

优先用本机字体确实支持且形态正确的 Unicode 字根。非成字片形优先从对应宋体字的实际轮廓取形，再按参考删笔或重绘，统一填充 SVG 与文字说明。先检查字体轮廓，再选择轮廓或裁剪范围。轮廓编号与当前字体文件相关，更换字体后逐项复核。

小字根按可见墨迹居中，保留字形本来的宽窄。首项键名单独留宽。检查偏旁左右留白、部件间隙、开口方向、上下重心、末笔和裁剪残点。Q 的无尾鱼曾因裁剪保留末横尖角，N 的折钩曾留下乃左撇残点。Pillow 多边形预览与实际 SVG 填充可能不同，疑点用真实 SVG 渲染和浏览器复看。

每个片形同时查看实际键帽大小与放大图。Q/E 的少数低分辨率变体仍有辨形不确定性，改动须保留依据和说明。

## 重建与验证

依照 docs/README.md 配置 Python 和宋体。使用 scripts/rebuild.py 对单键或全表生成到 .qa，核对差异和预览后用 --apply 更新正式数据。预期修改会使比对命令非零退出，应确认差异符合本次改动。修改字形源脚本时同步运行重建，修改数据时同步更新逐键勘误。

当前 songti-v1 基线为 25 个字根键、216 项根区字根、16 项圈内笔画和 97 个 SVG 定义。docs/baseline.json 保存内容指纹、逐键数量与简码。仓库重组应保持内容完全相同。后续有依据的增删，在核对逐键差异后同步维护基线与文档。

运行 Python verify_data.py 和仓库 npm run check，并检查真实溢出、窄屏、200% 文字及两个组件实例的挂载/卸载。相关浏览器夹具在 tools/qa 中。

## 后续楷体版

kaiti-draft-v1 保存原楷体待完善版。完善楷体时复用键位与字根清单，明确记录每套字体对应的片形资源和核形结果。字体与片形风格一并校对，再考虑在界面提供可用版本入口。
