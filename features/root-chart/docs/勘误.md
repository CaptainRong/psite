每键按从上到下、每行从左到右登记，`／` 分隔参考图原有行。一个完整可见形体计一项，印刷变体分别登记，键名数字、字母、一级简码不计。参考图无红圈，新版把相应单笔画或组合笔画移入圆圈后，从字根区扣除，圈内另计一项。

参考图分辨率仅 1480 × 750。没有合适 Unicode 字符的片形以来源字和笔画描述登记，几何描述用于定位原图具体项。疑难形体须在分键绘制时复看放大图，不能根据近似名称自行补笔。

- Q、E、A、N、H、D、L 经过交叉复核，并用实际 SVG 渲染检查。修除了 Q 无尾鱼的末横残尖和 N 横折弯钩的孤立残点。大多数片形取自对应宋体汉字，少数印刷变体按可见笔势重绘。Q 的夕类、并足儿以及 E 的衣底细微变体受参考图分辨率限制，仍保留辨形不确定性。
